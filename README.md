# Apple 风格 Anki 问答模板

一套面向中文问答卡片的 Anki 模板，采用接近 Apple / iOS 的简洁视觉风格，并针对桌面端与移动端做了响应式适配。

## 特性

- 自动适配浅色 / 深色模式
- 支持 Anki `nightMode` / `night_mode`
- 问题、答案、笔记、相关知识分区展示
- Tags 徽标显示
- 自动显示复习时间
- 图片自适应视口，避免超出屏幕
- 点击图片放大，再次点击、点击空白处或按 `Esc` 收回
- 表格自动增强并支持横向滚动
- `pre` / `code` 自动套用代码样式
- 尊重系统“减少动态效果”设置
- 针对 AnkiMobile / AnkiDroid 等小屏设备优化排版
- 纯 HTML + CSS + JavaScript，无第三方依赖

## 预览结构

正面：

- 顶部栏：Tags（无标签时显示“问题”）+ 当前时间
- Tags 徽标
- 问题正文

背面：

- 保留正面内容
- 答案
- 笔记（可选）
- 相关知识（可选）

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `front.html` | 卡片正面模板 |
| `back.html` | 卡片背面模板 |
| `style.css` | 卡片样式 |
| `_x_ios.svg` | “问题”图标 |
| `_y_ios.svg` | “答案 / 笔记”图标 |
| `_z_ios.svg` | “相关知识”图标 |

## 所需字段

笔记类型需要包含以下字段，名称必须完全一致：

- `问题`
- `答案`
- `笔记`
- `相关知识`

`Tags` 为 Anki 内置特殊字段，无需手动创建。

其中：

- `问题` 是必需字段。
- `答案`、`笔记`、`相关知识` 均可为空；为空时对应区块不会显示。
- `相关知识` 使用 Anki 的 `hint:` 过滤器，默认以可展开提示形式显示。

## 安装

### 1. 创建或修改笔记类型

在 Anki 中打开笔记类型管理，确保存在：

`问题`、`答案`、`笔记`、`相关知识`

四个字段。

### 2. 设置卡片模板

打开 **卡片… / Cards…**：

- 将 `front.html` 的内容复制到“正面模板”
- 将 `back.html` 的内容复制到“背面模板”
- 将 `style.css` 的内容复制到“样式”

### 3. 安装图标媒体

将以下三个文件放入当前 Anki 配置的媒体目录（`collection.media`）：

`_x_ios.svg`、`_y_ios.svg`、`_z_ios.svg`

文件名前的下划线是有意保留的，适合用于模板级媒体资源。安装后正常执行 Anki 同步，即可让其他设备获取这些媒体文件。

## 使用说明

### 图片

模板会自动让正文图片适应当前视口。点击图片可放大；以下任一操作均可退出放大：

- 再次点击图片
- 点击图片以外的空白区域
- 按 `Esc`

如某张图片不希望启用点击放大，可在 HTML 中添加：

```html
<img src="example.png" class="no-zoom">
```

或：

```html
<img src="example.png" data-nozoom="1">
```

### 表格

普通 HTML `table` 会自动套用模板表格样式。较宽表格可横向滚动，避免在手机上压缩得过窄。

### 代码

`pre` 与 `code` 会自动套用代码样式。字体优先使用：

`Maple Mono NF CN` → `JetBrains Mono` → 系统等宽字体。

即使设备没有安装前两种字体，也会正常回退。

## 深色模式

模板同时兼容：

1. 系统 `prefers-color-scheme: dark`
2. Anki 的 `.nightMode` / `.night_mode`

因此桌面端和移动端通常不需要额外维护两套样式。

## 兼容性说明

模板使用现代 CSS 与 JavaScript，但为 `backdrop-filter` 提供了回退样式。建议使用较新的 Anki、AnkiMobile 或 AnkiDroid 版本。

模板中的 JavaScript 初始化设计为可重复执行：翻到背面后，新增的答案、笔记、相关知识区域中的图片、表格和代码块也会重新扫描并增强，同时通过状态标记避免重复绑定事件。

## 自定义

常用视觉参数集中在 `style.css` 顶部的 `:root` 中，例如：

```css
:root {
  --ios-radius: 14px;
  --fs-base: clamp(1rem, 2.5vw, 1.25rem);
  --fs-title: clamp(1.15rem, 3vw, 1.35rem);
  --lh: 1.6;
}
```

如果只想整体调大或调小字号，优先调整 `--fs-base` 与 `--fs-title`，比在多个选择器中分别修改更容易维护。

## 维护原则

- 保持零第三方依赖
- 优先保证桌面端与移动端的一致体验
- 新增交互必须可重复初始化，避免正反面切换导致功能失效
- 模板媒体统一使用固定文件名，避免 CSS 引用失效
- 视觉调整优先通过 CSS 变量完成
