导入笔记

支持完整 JSON 备份、同名字段的 CSV / TSV，以及外部 AI 返回的 JSON 数组。先检查，再加入当前草稿。

相同 GUID 更新原笔记；类型不能改变。没有 GUID 的笔记作为新笔记。检查不通过的内容可先作为草稿修正；字段结构或媒体格式错误会阻止导入。导入可撤销。

带到 Anki，或备份草稿

JSON 完整备份

包含字段、标签、GUID、牌组和全部本地图片，可再次导入继续编辑。

Anki 导入文件与图片

ZIP 内每种笔记类型一份 TSV，附带媒体和备份。先导入项目安装包，再把媒体复制到 collection.media，导入 TSV。无需安装开发环境。

生成 .apkg

在本地运行项目现有生成器，读取刚导出的 JSON。官方 Anki 后端会生成原生卡片、媒体和预览，操作临时集合。 

python scripts/build_package.py --input 我的制卡.json --output build/我的制卡.apkg --preview build/我的制卡预览.json

在外部 AI 整理材料

生成提示词后复制到你选择的 AI 对话。返回的 JSON 使用本项目原生字段；回到「导入」检查、修正并预览。

提示词只在本页生成。发送给外部 AI 前自行确认材料，导入后核对事实、答案与来源。
